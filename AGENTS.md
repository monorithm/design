# Rules for agents in this repository

- This repository is the source of the Monorithm Experience Language. It is greenfield. Do not copy files or history from an archived repository or from a private repository.
- Write all text in ASD-STE100 Simplified Technical English.
- Take each value from the language: the design canvas until this source has it, then this source. Do not invent a value.
- A contract tells the language only: the anatomy, the states, the keyboard model, and the moments. It has no code and no name of a stack or a library.
- This repository can be public. Do not add these items:
  - A private name
  - The ID of a decision or of a private process
  - The name or the version of a canvas board
  - The name of a private repository
- Use Yarn Berry. Do not add a lockfile of a different package manager.
